# GH-16 - writing-plans: hand-off lines still announce docs/ultrapowers/plans/ when a ticket routes the plan to plans/ID/Plan.md

## Context
With a ticket, writing-plans saves the plan to `plans/<ID>/Plan.md` (its knowledge-base route), but the two hand-off lines near lines 190 and 199 of `skills/writing-plans/SKILL.md` still tell the human partner the plan was saved to `docs/ultrapowers/plans/<filename>.md`. The ticket asks for one pressure run on a ticketed project first, then a fix of the hand-off wording through writing-skills if the run shows the wrong path.

## Definition of Ready
- [ ] A ticketed fixture project exists where writing-plans routes the plan to `plans/<ID>/Plan.md`.

## Definition of Done
- [ ] One pressure scenario (ticketed project, writing-plans hand-off) is recorded with the path the hand-off announced before and after.
- [ ] The hand-off lines name the path the plan was saved to, for a ticket and for a project without one.
