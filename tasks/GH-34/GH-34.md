# GH-34 - task-review --post: screenshots do not render on a private repository

## Context
With `task-review --post` on GitHub or GitLab, `post-review.mjs` embeds the QA report's screenshots through the raw file URL of the pushed documents branch (`raw.githubusercontent.com/...` or GitLab `/-/raw/...`). On a private repository that URL needs a token, so the image does not render in the issue or pull request comment and only the link text shows. This task makes the screenshot render on a private repository, or makes the comment say plainly that it is a link to the file in the repository.

## Definition of Ready
- [ ] A private repository to test against is agreed (the blob URL with the raw parameter, or an upload where the forge API allows it, is the direction named in the ticket)

## Definition of Done
- [ ] A `task-review --post` on a private GitHub repository shows the screenshot in the comment, or the comment states the file's location in the repository
- [ ] `tests/task-lifecycle/post-review.test.mjs` covers the new link form for GitHub and GitLab
